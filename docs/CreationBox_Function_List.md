# CreationBox 功能列表

## 1. 功能总览

| 模块 | 功能 | 优先级 | 当前状态 | 说明 |
| --- | --- | --- | --- | --- |
| 全局 | 左侧工具导航 | P0 | 已原型 | 三个核心工具切换 |
| 全局 | 明暗模式切换 | P0 | 已原型 | 支持本地主题切换 |
| 全局 | 登录/注册入口 | P2 | 预留 | 仅 Toast 提示 |
| 全局 | 今日免费次数 | P2 | 已原型 | 本地模拟次数变化 |
| 结果 | 复制结果 | P0 | 已原型 | 复制主要结果文本 |
| 结果 | 导出 Markdown | P0 | 已原型 | 生成 `.md` 文件 |
| 结果 | 重新生成 | P0 | 已原型 | 使用当前输入重新生成 |
| 结果 | 清空输入 | P0 | 已原型 | 清空输入并重置结果 |

## 2. AI痕迹去除

| 功能 | 优先级 | 输入 | 校验 | 输出 |
| --- | --- | --- | --- | --- |
| 极速模式 | P0 | 文本 | 小于 600 字 | 优化后正文、建议、对比、洞察 |
| 长文本模式 | P0 | 文本 | 小于 2500 字 | 优化后正文、建议、对比、洞察 |
| 文件导入模式 | P1 | txt/markdown/pdf | 文件格式 | 模拟导入结果 |
| 字数计数 | P0 | 文本 | 实时展示 | 超限提示 |
| 文件格式提示 | P0 | 文件 | txt/md/markdown/pdf | 错误提示 |

不包含：

- 风格选择。
- 目标读者。
- 优化强度。
- 关键词保留。

## 3. 公众号文章仿写

| 功能 | 优先级 | 输入 | 输出 |
| --- | --- | --- | --- |
| 公众号链接输入 | P0 | 微信公众号链接 | 标题建议、大纲、正文示例 |
| 原文输入 | P0 | 文本 | 标题建议、大纲、正文示例 |
| 仿写目标 | P1 | 标题结构/行文框架/观点角度/案例叙事/完整草稿 | 影响模拟文案 |
| 文章语气 | P1 | 专业克制/亲和口语/观点犀利/温暖叙事/品牌官方 | 影响模拟文案 |
| 关键词方向 | P2 | 关键词文本 | 追加到模拟结果 |

## 4. 生成文章

| 功能 | 优先级 | 输入 | 配置 | 输出 |
| --- | --- | --- | --- | --- |
| 主题生成 | P0 | 文章主题、补充素材 | 内容类型、文章语气、关键词 | 标题、正文、结尾建议 |
| 参考链接生成 | P0 | 新闻/博客/官网/公众号等链接 | 无 | 标题、正文、结尾建议 |

参考链接模式不展示：

- 内容类型。
- 文章语气。
- 关键词。

## 5. 结果区功能

| 功能 | 优先级 | 启用条件 | 行为 |
| --- | --- | --- | --- |
| 评分展示 | P1 | 生成成功 | 展示自然度/结构匹配度/草稿完整度 |
| 复制结果 | P0 | 生成成功 | 复制主要结果文本 |
| 导出 Markdown | P0 | 生成成功 | 下载当前结果 `.md` |
| 重新生成 | P0 | 生成成功 | 保留输入并重新生成 |
| 空态提示 | P0 | 未生成 | 提示用户先输入内容 |
| Loading | P0 | 生成中 | 禁用生成按钮并展示处理中 |

## 6. 校验规则

| 场景 | 规则 | 提示 |
| --- | --- | --- |
| 空输入 | 必填项为空时不能生成 | 请先填写对应内容 |
| 极速模式超限 | 输入超过 600 字 | 极速模式最多支持 600 字 |
| 长文本模式超限 | 输入超过 2500 字 | 长文本模式最多支持 2500 字 |
| 文件格式错误 | 非 txt/md/markdown/pdf | 文件导入模式仅支持 txt、markdown、pdf |
| 复制失败 | Clipboard 不可用 | 当前浏览器不支持直接复制 |
