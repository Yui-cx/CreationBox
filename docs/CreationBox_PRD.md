## 2. 背景分析

AI 写作已经显著提升内容生产效率，但公众号运营者在实际使用中仍面临三个问题：

1. AI 生成内容容易出现表达模板化、句式机械、阅读节奏单一的问题。
2. 内容运营者需要基于热点、链接、竞品文章快速生成公众号草稿，但不希望操作流程过重。
3. 公众号仿写、改写、生成属于高频轻工具场景，用户更关注输入快、结果快、可复制、可导出。

CreationBox 初版定位为面向公众号场景的 AI 文本工作台，先用静态可交互原型验证核心工作流，不接入真实模型、账号、支付和后端。

## 3. 痛点挖掘

| 用户痛点 | 具体表现 | 产品机会 |
| --- | --- | --- |
| AI 文本机械感明显 | 句式重复、连接词生硬、段落像模板 | 提供轻量的自然表达优化工具 |
| 文章仿写成本高 | 需要拆标题、结构、段落节奏 | 将参考链接或原文转为标题、大纲、正文示例 |
| 生成公众号初稿慢 | 从主题、素材到正文需要多轮整理 | 提供主题生成和参考链接生成两种入口 |
| 工具链割裂 | 生成后还要复制、整理、存档 | 提供复制结果和 Markdown 导出 |

## 4. 核心策略

1. 工具优先：首屏即工作台，不做营销型落地页。
2. 低配置：优先减少用户决策成本，尤其是 AI 痕迹去除功能。
3. 三工具闭环：围绕优化、仿写、生成覆盖公众号内容的主要前置流程。
4. 结果可带走：所有工具生成后支持复制和 Markdown 导出。
5. 合规表达：页面强调自然表达优化、可读性提升、草稿生成，不承诺任何检测规避结果。

## 5. 产品范围

### 5.1 本期范围

- 左侧工具导航：AI痕迹去除、公众号文章仿写、生成文章。
- 顶部状态栏：产品说明、主题切换、登录/注册预留入口。
- 输入区：根据工具和模式动态显示输入控件。
- 结果区：展示评分、正文结果、对比、编辑洞察。
- 操作能力：生成、复制、重新生成、清空输入、导出 Markdown。
- 明暗模式：支持浅色和深色主题。
- 静态模拟：所有结果均为本地 mock。

### 5.2 本期不做

- 不接真实 AI 模型。
- 不接后端接口。
- 不做账号体系、历史记录、会员套餐和支付。
- 不做真实链接抓取。
- 不做真实文件解析。
- 不承诺检测通过率或规避检测。

## 6. 用户与场景

### 6.1 核心用户

公众号运营者、内容编辑、自媒体创作者。

### 6.2 典型场景

1. 用户有一段 AI 草稿，希望快速优化成更自然的公众号表达。
2. 用户看到一篇参考文章，希望提取结构并生成仿写草稿。
3. 用户有一个选题或新闻链接，希望快速生成公众号初稿。
4. 用户生成内容后，需要复制到编辑器或导出 Markdown 存档。

## 7. 功能设计

### 7.1 全局布局

- 左侧导航：展示三个核心工具，当前选中项高亮。
- 顶部栏：展示产品定位、主题切换、登录/注册预留入口。
- 主工作区：左侧为输入面板，右侧为结果面板。
- 移动端：左侧导航折叠为横向工具切换条。

### 7.2 AI痕迹去除

目标：降低文本机械感，优化成更自然的公众号表达。

输入模式：

| 模式 | 输入 | 限制 |
| --- | --- | --- |
| 极速模式 | 文本输入 | 小于 600 字 |
| 长文本模式 | 文本输入 | 小于 2500 字 |
| 文件导入模式 | 文件上传 | 支持 txt、markdown、pdf |

交互规则：

- 默认进入极速模式。
- 极速模式和长文本模式显示文本框与字数计数。
- 文件导入模式隐藏文本框，只显示文件选择控件。
- 不显示风格、目标读者、优化强度、关键词保留。
- 超出字数或文件类型不支持时，在输入区底部给出错误提示。

输出内容：

- 自然度评分。
- 优化后正文。
- 编辑建议。
- 处理前/处理后对比。
- 编辑洞察。

### 7.3 公众号文章仿写

目标：基于公众号链接或原文生成仿写结构和正文示例。

输入模式：

- 公众号链接。
- 粘贴原文。

配置项：

- 仿写目标：标题结构、行文框架、观点角度、案例叙事、完整草稿。
- 文章语气：专业克制、亲和口语、观点犀利、温暖叙事、品牌官方。
- 关键词方向：可选。

输出内容：

- 标题建议。
- 结构大纲。
- 仿写正文示例。
- 处理前/处理后对比。
- 编辑洞察。

### 7.4 生成文章

目标：基于主题或参考链接生成公众号文章草稿。

输入模式：

| 模式 | 输入 | 配置项 |
| --- | --- | --- |
| 主题生成 | 文章主题、补充素材 | 内容类型、文章语气、关键词 |
| 参考链接 | 新闻、博客、官网、公众号等链接 | 无额外配置 |

交互规则：

- 主题生成模式显示主题、补充素材、内容类型、文章语气、关键词。
- 参考链接模式只显示链接输入，不显示内容类型、文章语气、关键词。
- 参考链接模式不限制为微信公众号文章。

输出内容：

- 文章标题。
- 文章正文。
- 结尾行动建议。
- 处理前/处理后对比。
- 编辑洞察。

### 7.5 结果操作

所有工具生成结果后支持：

- 复制结果：复制主要结果文本。
- 导出 Markdown：导出 `.md` 文件。
- 重新生成：基于当前输入重新生成模拟结果。
- 清空输入：清空当前输入并重置结果区。

Markdown 导出内容：

- 工具名称。
- 评分说明。
- 生成结果。
- 处理前/处理后。
- 编辑洞察。

## 8. 状态与异常

| 状态 | 触发条件 | 页面反馈 |
| --- | --- | --- |
| 初始态 | 未生成结果 | 结果区显示空状态 |
| 空输入 | 点击生成但无输入 | 输入区底部显示错误 |
| 加载中 | 点击生成后 | 生成按钮禁用，结果区显示 loading |
| 成功态 | 模拟生成完成 | 展示结果，启用复制/导出/重新生成 |
| 字数超限 | AI痕迹去除文本超过限制 | 显示模式对应字数上限 |
| 文件格式错误 | 上传非 txt/markdown/pdf | 显示格式限制提示 |
| 复制失败 | 浏览器不支持 Clipboard | Toast 提示复制不可用 |

## 9. 数据指标

初版原型阶段关注行为验证，不展示在页面中。

| 指标 | 定义 | 目标用途 |
| --- | --- | --- |
| 工具启动率 | 进入页面后点击生成的用户占比 | 判断工具入口清晰度 |
| 生成完成率 | 点击生成并成功看到结果的占比 | 判断流程顺畅度 |
| 复制率 | 生成后点击复制的占比 | 判断结果可用性 |
| 导出率 | 生成后点击导出 Markdown 的占比 | 判断沉淀和复用价值 |
| 模式使用占比 | 三个工具和各模式的使用比例 | 指导后续优先接入真实 AI 的顺序 |

## 10. 验收标准

1. 页面默认进入 AI痕迹去除的极速模式。
2. AI痕迹去除不展示风格、目标读者、优化强度、关键词保留。
3. 生成文章的参考链接模式不展示内容类型、文章语气、关键词。
4. 三个工具均可生成模拟结果。
5. 三个工具生成后均可复制和导出 Markdown。
6. 明暗模式切换可用。
7. 移动端无横向滚动，核心输入和按钮可正常操作。
8. 页面不出现保证通过检测、规避检测等承诺性文案。
